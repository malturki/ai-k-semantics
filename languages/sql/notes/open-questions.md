# SQL Open Questions

- Which exact SQL/Foundation feature set should define the first "core" milestone?
- How should optional SQL:2023 features be represented in manifests and test selection?
- Can we obtain licensed access to ISO/IEC 9075-2:2023 and 9075-11:2023 for section-level provenance?
- Which historical NIST/FIPS SQL conformance artifacts are still available, licensed for use, and relevant to SQL:2023?
- Which vendor engines should be used as non-authoritative differential profiles first?
- What normalization rules are acceptable for diagnostics, collation, numeric precision, timestamps, and implementation limits?
